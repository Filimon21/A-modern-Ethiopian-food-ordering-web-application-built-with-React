# Addis Eats

Addis Eats is a modern React food ordering application inspired by Addis Ababa.

## Features

- Responsive restaurant homepage
- Ethiopian food menu
- Category filtering
- Search
- Dish details
- Shopping cart
- Quantity management
- Checkout
- Form validation
- Delivery estimate
- LocalStorage order history
- Favorites
- Light and dark theme
- React Router
- Admin dashboard
- Admin login
- Dish management
- Order management
- Responsive UI

## Technologies

- React
- React Router
- Vite
- JavaScript
- CSS
- LocalStorage
